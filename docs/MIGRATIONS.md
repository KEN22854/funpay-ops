# Миграции базы данных

База — SQLite (`data/funpay-ops.db`, встроенный `node:sqlite`). Миграции применяются автоматически при запуске сервера, в транзакции, по одной. Применённые версии записаны в таблице `schema_migrations`.

| Версия | Релиз | Что добавлено |
|---|---|---|
| v1 | 2.0.0 | Основные таблицы: настройки, аудит, идемпотентность, каталог, сканы, решения сопоставления, комиссии, история цен, здоровье источников, рекомендации, закупки, продажи, движения склада, резервы, касса, уведомления, бэкапы |
| v2 | 2.1.0 | Версия движка и параметров у рекомендаций; качество данных в здоровье источников; перепроверки; попытки закупки; частичное исполнение; резерв денег; paper trading; прогоны бэктеста |
| v3 | 2.1.0 | Параметры расчёта у бумажных позиций |
| v4 | 2.2.0 | Исход перепроверки (ok / incomplete / failed / blocked) отдельно от цены; режим и отпечаток входных данных бэктеста; постоянные сессии (хэши); журнал ошибок API; шифрованные копии и учения по восстановлению |

## Правила

1. **Применённую миграцию не изменять.** Любое изменение схемы — новая версия в конце `server/db/migrations.mjs`.
2. **Только расширение.** Можно добавлять таблицы, столбцы и индексы. Удаление и переименование — через новую таблицу с переносом данных в той же миграции.
3. **Перед релизом** выполнить проверку на копии рабочей базы:

   ```bash
   npm run db:check
   ```

   Скрипт копирует `data/funpay-ops.db` во временную папку, применяет миграции и проверяет:
   - `integrity_check` и внешние ключи;
   - что повторное открытие ничего не меняет;
   - что бэкап создаётся и проходит тест восстановления.

   Рабочая база при этом не меняется. CI делает то же на пустой базе (`--fresh`).
4. **Бэкап** создаётся автоматически раз в сутки и перед каждым восстановлением. Перед обновлением версии полезно создать копию вручную: «Настройки → Резервные копии → Создать сейчас».
5. **Откат.** Восстановите копию, сделанную до обновления, и запустите предыдущую версию приложения (`git checkout v<версия>`). Более новая схема со старой версией кода не используется.
